# Historical source archive

These files preserve the source research material. They include earlier workbooks, provisional prices, project findings and the unmodified original S1 simulator. For the paper's active evidence-supported scope, run `python reproduce.py` from the repository root.

The historical S1 simulator can be run from `s1_original/`, but its price-dependent CT-07–CT-09 checks and numerical cost output are excluded from the current paper's validation count. Original notes may contain earlier scope descriptions and should not override the working manuscript or active experiment profile.
