# Prototype supporting material

`catalogue/` contains ten hardware CSV datasets. `rules/` contains the supplied rule tables, source registers, ID mappings, gap analyses, QA sheets and the original rules workbook. `formula_workbooks/` contains the eight workbooks extracted from the supplied physics package.

These files are supporting material for a future prototype. They are not the benchmark performance catalogue used by S1 or S2, and they have not been normalized or revalidated as production recommendation rules. Estimates, uncertain fields and earlier variants are retained as supplied.
